- Refs are extracted from props and passed to createVNode
- No automatic ref forwarding is implemented

2. Required Changes:
a) Modify createElement function to:
   - Handle ref forwarding for function components
   - Preserve existing ref behavior for class components
   - Maintain backward compatibility

   - Support forwarded refs
   - Handle both direct refs and forwarded refs
